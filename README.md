# Loan Approval Prediction using Machine Learning

## Project Overview
This project focuses on analyzing loan applicant data and building machine learning classification models to predict whether a loan application will be approved or rejected.

The project combines Exploratory Data Analysis (EDA) and Machine Learning to identify patterns in applicant information and evaluate different classification algorithms.

## Project Objectives
- Understand and analyze loan applicant data.
- Perform data cleaning and preprocessing.
- Explore relationships between applicant features and loan approval.
- Build and evaluate multiple machine learning models.
- Identify the best-performing classification model.

## Dataset Description
- **Dataset:** Loan Prediction Dataset
- **Original Records:** 614
- **Features:** 12 input features and 1 target variable.
- **Target Variable:** Loan_Status
  - Y – Approved
  - N – Rejected

## Machine Learning Models
The following classification algorithms were implemented:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 86.18% |
| Support Vector Machine | 84.55% |
| Random Forest | 83.74% |
| K-Nearest Neighbors | 81.30% |
| Decision Tree | 71.54% |

## Best Model
**Logistic Regression** achieved the highest test accuracy of **86.18%** among the five models evaluated.

Model performance was assessed using accuracy, confusion matrices, precision, recall, and F1-score.

## Conclusion
This project demonstrates how Exploratory Data Analysis and Machine Learning can be used to study loan approval patterns and predict loan application outcomes.

Among the five classification models, Logistic Regression achieved the highest accuracy on the test dataset.
